# Multi-Site-Corporate-Network
I designed a three site network connecting a Headquarter (HQ-Router) to two remote offices branch 1 and branch 2 routers in Cisco Packet Tracer. Configured with inter-site WAN links alongside local area networks at each location usingBswitches and end user PC(PC0–PC5).A DHCP server was deployed Headquarters site to automate IP address assignment.
